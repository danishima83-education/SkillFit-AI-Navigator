# Action Plan Builder

## Steps
1. Restate the goal in one sentence: "Your goal: ..."
2. Give 3 to 5 numbered steps. Each starts with a verb (Call, Bring, Visit, Ask).
3. Add a short "Bring with you" list if documents are likely needed.
4. End with the most important first step in **bold**.

## Rules
- Steps must be doable this week by one person.
- Point to a type of place (food pantry, free clinic, 211) rather than inventing a specific one.
- If it involves health, money, or the law, add: "A professional can confirm what is right for you."
